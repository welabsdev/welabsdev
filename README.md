### ⚙️ Low-Level & Embedded Systems Developer | Systems Programming | Firmware | Microcontrollers

I am a Brazilian developer focused on **low-level software, embedded systems, firmware, microcontrollers and systems programming**.

I enjoy working close to the hardware, understanding how systems behave below the abstraction layer and building solutions that connect **software, hardware, databases and infrastructure**.

I also have experience with backend development, real-time communication, relational databases, Linux servers and system integration.

- **Languages:** C, C++, C#, Assembly, PHP, JavaScript.
- **Low-Level & Embedded:** RTOS, Microcontrollers, Firmware Development, Firmware Modding, Embedded Systems, Reverse Engineering.
- **Hardware:** KiCad, PCB Design, Hardware Modding, Electronics, Hardware Diagnostics.
- **Systems:** Linux, Systems Programming, Kernel Development, Shell, SSH.
